# 🧠 Contextos (Context Engineering)

Nesta câmara, guardamos as essências que dão sabor e direção às nossas interações. O Context Engineering é a arte de fornecer à IA as informações de fundo necessárias para que ela não precise adivinhar nada.

## 📁 Categorias

*   **[SpecKit](./speckit/)**: Nossa metodologia de especificações estruturadas (Context Engineering pura).
*   **[DevComputaria](./devcomputaria/)**: O "tom de voz" e a filosofia da nossa comunidade.
*   **[Projetos](./projetos/)**: Contextos específicos para projetos internos ou open-source.
*   **[Tecnologias](./tecnologias/)**: Resumos e "cheat sheets" de stacks tecnológicas para injetar no prompt.

## 💡 Por que usar contextos prontos?

Porque repetir "sou um desenvolvedor Python usando Django e quero seguir as melhores práticas" em todo prompt é um desperdício de tokens e de sanidade. Injete um arquivo de contexto e vá direto ao ponto.
