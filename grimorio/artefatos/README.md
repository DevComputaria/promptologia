# 🏗️ Artefatos

Prompts que geram saídas estruturadas e úteis para o dia a dia.

## 📂 Categorias

- **[Código](./codigo/)**: Templates de funções, refatoração de classes, geradores de testes unitários.
- **[Documentação](./documentacao/)**: Geradores de README, explicadores de algoritmos, changelogs.
- **[Dados e Scripts](./dados-e-scripts/)**: Consultas SQL complexas, geradores de regex, workflows de automação.
- **[Criativo](./criativo/)**: Brainstorm de ideias, nomes para produtos/projetos.
