# ✨ O Ritual da Especificação (SpecKit Integration)

Este diretório contém a técnica para combinar o poder das especificações estruturadas (**SpecKit**) com a flexibilidade dos LLMs.

## 🏮 A Técnica

A integração consiste em fornecer à IA um template do **SpecKit** preenchido como a principal fonte de verdade para a tarefa solicitada. Isso força a IA a seguir regras de negócio estritas e formatos de dados pré-definidos.
