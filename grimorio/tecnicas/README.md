## 📂 O que explorar?

- **[Templates para Projetos](./templates-para-projetos/)**: Workflows complexos (ex: AI Product Development Toolkit).
- **[Few-shot, cadeia curta e autocrítica](./few-shot-cot-autocritica.md)**: Uma técnica por vez. O espécime é o gerador de commit.
- **[Eval control / edge / capability](./eval-control-edge-capability.md)**: Bateria conferível antes de promover um feitiço.
- **[Loop de agente com ferramentas](./loop-agente-com-ferramentas.md)**: Quando chamar, como ler retorno, quando parar.
