# 🧙‍♂️ O Grimório (Prompts)

Bem-vindo ao coração da Promptologia. Este diretório contém os "feitiços" propriamente ditos — prompts cuidadosamente (ou desesperadamente) elaborados para diversas finalidades.

Comece pelo **[Índice do Grimório](./INDEX.md)** para ver caminho, câmara, status e modelos testados de cada feitiço.

## 📁 Estrutura da Biblioteca

### 1. [Artefatos](./artefatos/README.md)
Prompts focados em **GERAR** coisas tangíveis.
- **[Código](./artefatos/codigo/)**: Classes, testes, refatorações.
- **[Documentação](./artefatos/documentacao/)**: READMEs, Swagger, Changelogs.
- **[Dados e Scripts](./artefatos/dados-e-scripts/)**: SQL, Regex, Workflows.
- **[Criativo](./artefatos/criativo/)**: Brainstorms e nomes de produtos.

### 2. [Arquivos de Contexto](./arquivos-de-contexto/README.md)
Prompts que **DEFINEM** como a IA deve se comportar.
- **[Persona](./arquivos-de-contexto/persona/)**: "Vista a máscara de um SRE cínico".
- **[Sistema](./arquivos-de-contexto/sistema/)**: Instruções de sistema (System Prompts) para segurança e revisão.
- **[Regras de Negócio](./arquivos-de-contexto/regras-de-negocio/)**: Contextos específicos de domínio.

### 3. [Técnicas](./tecnicas/README.md)
Frameworks e padrões de prompt engineering.
- Exemplos de Few-shot, Chain-of-Thought e Auto-reflexão.
- **[Templates para Projetos](./tecnicas/templates-para-projetos/)**: Combinações complexas de técnicas para fluxos de trabalho completos.

## 📜 Como escolher seu feitiço

1. Identifique se você quer que a IA **crie algo** (Artefatos) ou **se comporte de uma forma** (Arquivos de Contexto).
2. Se estiver buscando melhorar a qualidade das respostas de forma geral, explore a seção de **Técnicas**.
3. Copie, cole, adapte e não esqueça de oferecer um café virtual para a IA (ou para nós).
