# Como contribuir

1. Forka com responsabilidade (ou desespero).
2. Crie seu feitiço a partir do [`TEMPLATE.md`](./TEMPLATE.md) da raiz.
3. Para estruturas especializadas, consulte os modelos em [`grimorio/tecnicas/templates/`](./grimorio/tecnicas/templates/).
4. Gere o índice com `python3 scripts/index-grimorio.py` e valide com `python3 scripts/index-grimorio.py --check`.
5. Abra uma PR com título sarcástico mas explicativo.
6. Responda aos comentários com sabedoria ou memes.
