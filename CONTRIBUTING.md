# Como contribuir

1. Forka com responsabilidade (ou desespero).
2. Feitiço novo segue [TEMPLATE.md](TEMPLATE.md). Os modelos de seção continuam em [grimorio/tecnicas/templates/](grimorio/tecnicas/templates/).
3. Rode `python3 ferramentas/cli/check_grimorio.py` antes do push. O CI roda o mesmo script.
4. Não marque `battle-tested` sem `exemplos/responses/<id>.md` com conteúdo, data e modelo.
5. Não reescreva o corpo de arquivo `proveniencia: importado`. Atribua a fonte ou retire o arquivo.
6. Título da PR: sarcástico, mas explicativo.
7. O backlog está em [PLANO-DE-MUDANCAS.md](PLANO-DE-MUDANCAS.md). Eval com saída inventada não conta. Aposentadoria de CRUD, n8n e pentest é uma PR por item.
