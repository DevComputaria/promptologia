# promptologia - O Grimório Arcano de Context & Prompt Engineering

Bem-vindo ao repositório **promptologia**! Este é o epicentro da nossa busca coletiva para dominar a arte de conversar com Inteligências Artificiais. Aqui, transformamos o caos das interações com LLMs em feitiços estruturados e contextos poderosos.

Pense nisso como nosso grimório compartilhado para dobrar as IAs à nossa vontade (ou pelo menos para que elas gerem JSON válido sem reclamar).

## 🧙‍♂️ Navegando pelo Grimório

Abaixo, os portais para as diferentes câmaras do conhecimento:

*   **[📜 O Grimório](./grimorio/README.md)**: Onde os feitiços (prompts) vivem. Categorizados por artefatos, arquivos de contexto e técnicas avançadas.
*   **[🧠 Contextos](./contextos/README.md)**: Definições de domínio, manifestos e "temperos" prontos para injeção em qualquer conversa.
*   **[🛠️ Ferramentas](./ferramentas/README.md)**: Utilitários, scripts CLI e integrações (como n8n e Perplexity) para potencializar seu uso de IA.
*   **[🧪 Exemplos](./exemplos/README.md)**: Conversas reais e resultados obtidos. Veja a magia acontecendo na prática.
*   **[🌌 Arcano](./arcano/README.md)**: Conhecimento avançado, estudos teóricos e nossos RFCs (diretrizes caóticas).
