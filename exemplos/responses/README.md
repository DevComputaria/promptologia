# Respostas registradas

Ainda não há uma saída com modelo e data verificáveis nesta galeria. Ao adicionar uma:

1. informe o caminho do feitiço usado;
2. registre modelo e data da execução;
3. preserve as variáveis de entrada sem segredos ou dados pessoais;
4. inclua a resposta real, sem promovê-la silenciosamente a “resultado esperado”.

Arquivo vazio não é exemplo; esperança também precisa de evidência.
