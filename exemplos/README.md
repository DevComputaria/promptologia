# 🧪 Exemplos e Resultados

Teoria é bom, mas ver o código funcionando (ou a IA delirando) é melhor ainda.

## 📁 Galeria de Resultados

`responses/` só recebe saída real: data, modelo e o texto que o modelo devolveu. Arquivo vazio não entra. O contrato está em [responses/README.md](./responses/README.md).

Os dois arquivos que ocupavam esta pasta com zero bytes foram removidos. Não eram resultado.

## 🤝 Como contribuir com exemplos

Se você usou um prompt do grimório e obteve um resultado fenomenal (ou bizarramente engraçado), abra uma PR adicionando o resultado aqui. Ajuda outros promptologistas a saberem o que esperar.
